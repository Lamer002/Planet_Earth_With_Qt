# Planet Earth with Qt

Небольшой проект на C++ и Qt, в котором я экспериментировал с отрисовкой и анимацией Земли. Хотелось сделать не просто вращающийся круг с текстурой, а картинку с атмосферой, ночными огнями и плавным движением.

## Как это устроено

Отрисовка сделана через QPainter. Для движения используется QTimer, а разные визуальные слои совмещаются с помощью режимов композиции и прозрачности. В проекте также используются текстуры и SmoothTransformation, чтобы изображение выглядело аккуратнее при изменении масштаба.

Для меня это была практика работы с графикой в Qt: хотелось разобраться, как собирать изображение из нескольких слоёв и обновлять его в реальном времени.

## Сборка

Проект рассчитан на C++17, Qt 6 и CMake. Для сборки понадобится установленный Qt с комплектом разработки и подходящий компилятор.

Откройте проект в Qt Creator и настройте комплект сборки с Qt 6. Если используете CMake из терминала, команды зависят от установленного Qt и конфигурации среды.
