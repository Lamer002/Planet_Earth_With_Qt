# Planet Earth with Qt

Небольшой проект на C++ и Qt, в котором я экспериментировал с отрисовкой и анимацией Земли. Хотелось сделать не просто вращающийся круг с текстурой, а изображение с атмосферой, ночными огнями и плавным движением.

## Как выглядит

![Анимация Земли](https://github.com/user-attachments/assets/b1e0be9c-41a3-457c-a25e-22f4e596e706)

## Что использовал

- **QPainter** — отрисовка графики
- **QTimer** — обновление анимации
- Прозрачность и режимы композиции — совмещение визуальных слоёв
- **SmoothTransformation** — сглаживание при масштабировании

Мне было интересно понять, как собирать изображение из нескольких слоёв и обновлять его в реальном времени, не превращая всю логику в один большой обработчик.

## Как запустить

Нужны Qt с модулем Widgets, компилятор с поддержкой C++17 и Qt Creator.

1. Откройте в Qt Creator файл `WorkWithImage2.pro`.
2. Выберите установленный комплект Desktop Qt.
3. Соберите и запустите проект.

Здесь используется **qmake** (файл `.pro`), а не CMake.
